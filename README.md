# Employee Management System

A clean full-stack CRUD application built with React + Vite, Java Spring Boot, Spring Data JPA, and an H2 database.

## Features
- Create employees with name, employee ID, and address
- View all employee records
- Search by name, employee ID, or address
- Update existing employee details
- Form validation and readable API errors
- Responsive dashboard UI
- H2 file database so records persist between backend restarts

## REST API
| Method | Endpoint | Purpose |
|---|---|---|
| POST | `/api/employees` | Create an employee |
| GET | `/api/employees` | Get all employees |
| PUT | `/api/employees/{id}` | Update an employee by database ID |

Example POST body:
```json
{
  "name": "Rahul Kumar",
  "employeeId": "EMP101",
  "address": "Hyderabad, Telangana"
}
```

The database `id` is generated by the backend. `employeeId` is the employee's unique business ID.

## Database
The app uses an H2 file database stored under `backend/data/employee-db`. The database is created automatically when the backend starts. H2 console (development only): `http://localhost:8080/h2-console`


## Suggested development
1. Start backend and verify it starts on port 8080.
2. Test POST and GET in Postman.
3. Test PUT with the database ID returned by POST.
4. Start React and test create/list/edit from the UI.
5. Add unit tests, pagination, authentication, or deploy after the core flow works.
